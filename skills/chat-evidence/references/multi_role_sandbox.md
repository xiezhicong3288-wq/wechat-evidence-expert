# 多方视角分析

根据用户实际问题选用当事人、调查、审判、行政协调或监督审查视角。视角是分析方法，不代表真实人员、专业资格或机构意见，也不证明掌握机关内部信息。

## 输入与依据

以同一份可定位的原始材料、索引、时间线和身份缺口为底本。先区分已核实事实、用户主张、对方主张、推断和未知。哈希清单只辅助一致性核对，不把未验证导出变成真实性已确认的底本。

法律关系、管辖、程序、证据标准或时限需要现行权威原文时，查询适用地区和时间的官方来源并提供引用。检索用抽象法律问题，不在外部搜索词中包含未公开聊天、身份资料或案情秘密。缺少可靠来源时保留待核，不编造条文、案例或机关流程。

## 视角分工

| 视角 | 检查问题 |
| --- | --- |
| 当事人及法律分析 | 诉求、证据支持范围、不利材料、可行的补证动作 |
| 调查 | 事实能否独立验证、身份与资金链是否闭合、合法取证缺口 |
| 审判 | 主张与证据是否对应、真实性争议、相反解释、程序问题 |
| 行政协调 | 是否属于相应职权范围、可提交的具体请求、信息缺口 |
| 监督审查 | 对象和事项是否对应、有无具体事实、线索与结论是否混淆 |

## 输出

按“问题—证据位置—可支持的范围—反例/反驳—待核事项—具体下一步”组织。观点冲突保留并说明需要什么材料才能判断。没有统计或可比样本时不给精确胜诉率；不把对机构或人员动机的猜测写成事实。

仅讨论有事实根据的合法途径。不得捏造、诬告、贿赂、骚扰或提出违法施压方案。分析完成不等于获准发送材料、举报、联系第三方或公开个人信息；这些动作须有独立的有效授权。
