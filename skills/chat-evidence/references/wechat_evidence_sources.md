# 微信聊天证据与官方资料

适用于中国大陆普通民事案件的材料整理。公开来源核验于 2026-11-19。先明确待证事实、授权的微信账号和会话范围，再按受理法院的通知核对举证期限、材料格式和原件核验要求。

## 留存与核对

1. 留存可供复核的原设备、微信内会话及原媒体。记录所见账号与会话标识、设备与客户端版本、操作人、当地时间和时区、选取范围、录制或导出方法。截图和录屏从可识别的账号资料进入会话，覆盖相关原文、必要上下文、系统提示和附件。涉及语音时保留原音频和可播放来源，转写另存并核对。已迁移、缺附件或原设备不可用时保留缺口。 [最高人民法院民事证据规定，第14、15、90、93、99条](https://ipc.court.gov.cn/zh-cn/news/view-6230.html)
2. 区分账号归属、事发时使用者和具体发言作者。显示名、备注、头像和导出中的发言字段只能提供线索。用相关时点的微信号或账号标识、可核对的资料页、对方承认、交易凭据及其他往来材料逐项印证，记录共享账号、改名或代操作等已知疑点。 [最高人民法院民事证据规定，第14、87、88、93条](https://ipc.court.gov.cn/zh-cn/news/view-6230.html)
3. 分别保留源导出、附件和资料来源记录，工作副本用于截取或遮挡无关隐私。记录 SHA-256、原路径或消息位置、每次转换、移交和缺失项。对照源件复核有利与不利记录。逐项写明材料支持哪一部分事实、仍需何种补强，以及目前能否与原会话核对。 [最高人民法院民事证据规定，第87、88、90、93条](https://ipc.court.gov.cn/zh-cn/news/view-6230.html)

### 微信官方功能的范围

- 微信隐私保护指引第1.35条说明聊天记录保存在用户终端，可自行备份或在设备间转移。第5.1.10条提供个人信息副本申请，公开说明没有承诺副本含聊天全文。个人信息副本、微信原生备份与本技能的会话 JSON 分别保留。 [微信隐私保护指引，2026-08-17更新并生效](https://oper.my-qcloud.com/cgi-bin/readtemplate?lang=zh_CN&s=privacy&t=weixin_agreement)
- 腾讯客服说明移动端可迁移全部或指定会话到另一台手机或平板，菜单名称因平台而异。Windows 客服说明从电脑恢复到手机会与该手机现有聊天合并。保留迁移前来源，记录两端设备、客户端版本、所选范围和已知变化。现有公开指引未证实通用可读聊天 JSON 导出接口，原生备份保持原样并使用微信支持的入口。 [腾讯客服移动端迁移](https://kf.qq.com/touch/wxappfaq/180122ua6NB7180122zI3AZR.html) · [腾讯客服 Windows 备份恢复](https://kf.qq.com/faq/161224mmmUju161224A3UVrE.html) · [腾讯客服记录保存规则](https://kf.qq.com/faq/161224feeE3I161224MrMvqY.html)

## 微信支付材料

1. 在授权账号内由账号持有人打开微信的“我 → 服务 → 钱包 → 账单”。财付通政策将“下载账单”列在账单页的常见问题中，实际菜单以客户端为准。记录下载范围与取得时间，留存收到的原文件及原交付记录。索取电子回单可能需要身份验证，由持有人在官方入口完成。 [财付通隐私政策修订公告，2026-08-24修订、2026-09-24生效](https://posts.tenpay.com/posts/4d1501526a8baf82000881c008b63f1d.html)
2. 如该笔账单详情提供“申请转账电子凭证”，按客户端提示操作。地方政务指引展示了从微信支付推送下载带财付通电子签章的 PDF 的流程。保存收到的原 PDF 和来源记录，有签章时注明核验方式及结果，条件不足标记待核。按实际可选的凭证类型和身份验证要求办理。 [宁国市政府网站发布的操作示例，2025-09-19](https://www.ningguo.gov.cn/OpennessContent/show/3597882.html) · [电子签名法，2019年修正，第5、8、13、14条](https://www.miit.gov.cn/jgsj/zfs/fl/art/2022/art_e3f623f70c23497e88a941170093446a.html)
3. 逐笔比对聊天中的金额和转账卡片、平台账单或凭证、相关银行或零钱流水。优先核对交易号，再核对时间与时区、准确金额和币种、付款/收款方向、账户线索、成功/待领取/退回/退款等实际状态。交易性质、双方合意与实际到账分别给出依据。仅有聊天中的金额、卡片或单方备注时，列出尚无凭据的事项。 [微信支付用户服务协议，2026-10-14修订、2026-11-13生效](https://posts.tenpay.com/posts/cbddf0af6088c4080432b952163ea238.html) · [北京政法网实务说明，2026-10-20](https://www.bjswzfw.gov.cn/sa1/yasf1/202610/t20261020_1682198.html)

## 提交与平台回执

- 即时通信、群组消息、身份认证、交易等信息属于电子数据范围。电子数据应提供原件，制作者制作且与原件一致的副本，或直接来源于电子数据的可显示、识别输出介质，可按第15条视为原件。视听资料的原始载体要求与电子介质中的视听资料适用电子数据规定，分别见第15条和第99条。材料说明应记录来源关系和核验条件，是否符合要求由法院审核。 [最高人民法院民事证据规定，法释〔2019〕19号修正，2020-05-01施行，2026-11-03重刊](https://ipc.court.gov.cn/zh-cn/news/view-6230.html)
- 第93条看形成、保管、传输和提取环境与方法。依第94条，记录和保存数据的中立平台提供或确认时，法院可以确认数据真实性，有相反证据足以反驳的除外。电子数据内容经公证的，法院应当确认其真实性，有相反证据足以推翻的除外。平台受理工单、申请或下载回执只记录其实际所载事项。区分平台提供的数据、核验覆盖的字段与期间，以及是否有账户或交易记录佐证。 [最高人民法院民事证据规定，第90、93、94条](https://ipc.court.gov.cn/zh-cn/news/view-6230.html)
- 在线提交须按法院指定方式。区分平台受理、材料审核、举证质证和法院认定。区块链技术核验一致时，法院可以认定上链后数据未被篡改，有相反证据足以推翻的除外。上链前数据来源与真实性仍须审查。本技能 SHA-256 只用于比较所持文件字节。 [人民法院在线诉讼规则，法释〔2021〕12号，2021-08-01施行，第11–13、15–18条](https://www.court.gov.cn/zixun/xiangqing/309551.html)
- 因客观原因无法自行取得的材料，按适用程序向法院说明拟调取项目、保管方、范围、线索、相关性及不能自行取得的原因。证据可能灭失或以后难以取得时，核对证据保全程序。第三方是否持有对应数据，按正式回执逐项确认。 [民事诉讼法，2023年修正，第67、84条](https://ipc.court.gov.cn/zh-cn/news/view-6231.html) · [民事诉讼法司法解释，2022年修正，第94–98条](https://ipc.court.gov.cn/zh-cn/news/view-6228.html)
