# 自我进化架构：三阶进化引擎

把每次整理暴露的识别误差、漏掉的法律语义、更优论证路径捕获、晋升、沉淀，skill 才越用越准。**「越用越准」只指识别与论证规则，绝不包括放宽能力边界。**本文供 SKILL.md 引用、脚本实现。

## 1. 三阶模型

| 阶 | 名称 | 动作 | 输出 |
| --- | --- | --- | --- |
| **阶 1** | 反思 Reflect | 每次任务后捕获「可教时刻」 | `vault/learnings/` 下 what-worked.md / what-failed.md |
| **阶 2** | 晋升 Promote | 同一经验复现 ≥3 次且过质量门 → 强制规则 | `rules/` 下规则（status=proposed 待审批） |
| **阶 3** | 沉淀 Distill | 反复出现的方案 → 人工拆出子 skill | 需人工审批后手工创建；**脚本不提供自动 promote 命令** |

**阶 1 自动、阶 2 需质量门、阶 3 需人工审批**。进化只影响识别/论证规则，绝不触碰原始聊天内容、哈希锚定与能力边界（不得把完整性校验升级成真实性证明，不得把当事人主张升级成已印证）。

## 2. 触发矩阵

| 信号 | 动作 |
| --- | --- |
| 用户纠正分类/论证 | 立即记 `corrections.md`，评估是否晋升 |
| 某类要素连续漏识（如「对赌」「承兑」） | 记 what-failed，提议扩充规则 |
| 同一规则反复触发且结果稳定（≥3 次） | 提议晋升为强制规则 |
| 某类任务反复出现且流程成熟 | 提议沉淀为子 skill |
| 外部法条/标准换版 | 更新 `references/export_schema.md` 附录并记录核验日期；**不得静默沿用废止版本** |
| 用户说「记住」「升级」「学到」 | 进入 Draft→Approve 循环 |

## 3. Compound Loop（每次进化都走）

```
DO WORK    ── 整理证据、生成论证
NOTICE     ── 发现可教时刻（识别错 / 漏了 / 有更优论证路径）
DRAFT      ── 起草变更：改词表 / 改规则 / 新建子 skill
PRESENT    ── 给出 current vs proposed + 理由，等用户确认
APPLY      ── 写回规则，记 config-history 与 daily log
COMPOUND   ── 下次任务从更准的规则起步
```

## 4. 质量门（DRAFT 后、APPLY 前必答）

1. 是**改进**还是只是「不同」？
2. 能在**未来证据任务**中复用（而非一次性上下文）？
3. 够**具体**（能写成 1–2 句无歧义规则）？
4. 够**通用**（不绑定某案件、某文件路径）？
5. **会不会破坏证据铁律**（只归类不篡改 / 本地 / 可溯源 / 边界诚实）？触碰则一票否决。
6. **会不会削弱可复核性**（改动后仍保证「同输入＋同工具版本＋同规则集 → 同一产物」）？

## 5. 晋升标准（阶 1 → 阶 2）

| 维度 | 阈值 |
| --- | --- |
| 复现 | 同一经验 ≥3 次且结果一致 |
| 稳定性 | 底层识别逻辑未变，不会立刻过时 |
| 影响 | 避免了错误，或显著节省时间 |
| 清晰 | 能写成 1–2 句无歧义规则 |
| 安全 | 不违反证据铁律，不放宽能力边界 |

## 6. 回归检测

每次晋升后，用**同一份已锚定样本**重跑关键子命令。基线绑定三元组：输入文件 sha256、工具版本、规则集哈希。输入不同或版本变化时 `regress` **拒绝比较**——跨样本的类别命中数对比只会制造「通过」的假象。命中数只覆盖词表粗筛，**不替代人工通读**：关键词法必然漏识，命中数上升也可能是假阳性增加。异常时回滚晋升。

**换样本 / 工具升级后如何重建基线**：确认旧基线不再需要，删除 `vault/baselines/baseline.json`，用新样本重跑 `regress` 即建立新基线。工具版本变化时 `regress` 会打印「命中数不可直接比较」并继续，此时同样应重建基线，不要把提示当成通过。`vault/` 已进 `.gitignore`，删除它不影响任何证据产物（产物本身不含本机时钟，可随时复算）。

## 7. 记忆目录

```
chat-evidence/
├── vault/
│   ├── learnings/{what-worked.md, what-failed.md}
│   ├── corrections.md            # 最近 50 条用户纠正
│   ├── config-history/YYYY-MM-DD.md
│   └── baselines/                # 回归基线（绑定三元组）
└── rules/                        # 阶 2 产物
```

（`vault/` 与证据产出目录均进 `.gitignore`，不外发、不提交。）
